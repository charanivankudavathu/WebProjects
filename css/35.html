CSS • Experiment 35

CSS Overflow Properties

Demonstration of overflow: visible, hidden, scroll and auto.

overflow: visible

This content is intentionally wider than its container. With overflow set to visible, the content can extend outside the box.

overflow: hidden

This content is intentionally wider than its container. The hidden value clips the content that goes outside the box.

overflow: scroll

This content is wider than the container. Scrollbars are always available with the scroll value.

overflow: auto

This content is wider than the container. The browser displays scrollbars when necessary.

Overflow Properties

visible: Content can extend outside the box.

hidden: Extra content is clipped.

scroll: Scrollbars are provided.

auto: Scrollbars appear when required.
