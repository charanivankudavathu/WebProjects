CSS • Experiment 08

Float and Clear Properties

Demonstration of floating elements and clearing the float using CSS.

FLOAT

The float property moves an element to the left or right side of its container. Other content can flow around the floated element.

In this example, the black box is floated to the left and the paragraph text flows around it.

Clear Property

The clear property prevents an element from appearing beside a floated element.
