clamp(), min() and max()

Demonstration of CSS mathematical sizing functions.

clamp()

The heading has a minimum, preferred and maximum font size.

font-size: clamp(28px, 6vw, 70px);

min()

This element uses min(100%, 600px).
width: min(100%, 600px);

max()

This element uses max(300px, 50%).
width: max(300px, 50%);
