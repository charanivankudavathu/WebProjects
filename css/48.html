Two-Column Webpage Layout

A two-column responsive layout created using CSS Grid.

Main Content

CSS Grid allows a webpage to be divided into multiple columns and rows.

In this example, the main content occupies two parts of the available space while the sidebar occupies one part.

The layout automatically changes to one column on smaller screens.
