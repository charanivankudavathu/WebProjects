SERVER-01

Implement a basic Client-Server Architecture using Node.js

Demonstrate communication between a client and a Node.js server.

Objective

To understand the basic client-server architecture and demonstrate how a client communicates with a Node.js server.

Node.js Code

const http = require("http");

const server = http.createServer((req, res) => {
    res.writeHead(200, {
        "Content-Type": "text/html"
    });

    res.end("<h1>Hello from Node.js Server</h1>");
});

server.listen(3000, () => {
    console.log("Server running at http://localhost:3000");
});

How to Run

Open Terminal inside the server folder and execute:

node 01.js

Then open http://localhost:3000 in your browser.

Expected Output

Hello from Node.js Server
