SERVER-07

Demonstrate the Path (path) module

Work with file and directory paths using Node.js.

Objective

To demonstrate commonly used functions of the Node.js path module.

Node.js Code

const path = require("path");

const filePath = path.join(
    __dirname,
    "files",
    "example.txt"
);

console.log("Complete Path:");
console.log(filePath);

console.log("Directory:");
console.log(path.dirname(filePath));

console.log("File Name:");
console.log(path.basename(filePath));

console.log("Extension:");
console.log(path.extname(filePath));

How to Run

node 07.js

Expected Output

Complete file path
Directory path
File name: example.txt
Extension: .txt
