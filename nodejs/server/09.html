SERVER-09

Install and use packages using npm

Install an npm package and use it in a Node.js application.

Objective

To demonstrate how npm can be used to install and use external packages in Node.js.

Install Package

npm init -y
npm install chalk

Node.js Code

const chalk = require("chalk");

console.log(chalk.bold("Node.js npm Package Demo"));
console.log(chalk.green("Package installed successfully."));
console.log(chalk.blue("This message uses the chalk package."));

How to Run

node 09.js

Expected Output

Node.js npm Package Demo
Package installed successfully.
This message uses the chalk package.
