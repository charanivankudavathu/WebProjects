Demonstrate Callbacks, Promises, and Async/Await in Node.js

Demonstrate three approaches for handling asynchronous operations.

Objective

To understand callbacks, Promises, and async/await for asynchronous programming in Node.js.

Node.js Code

function callbackExample(callback) {
    setTimeout(() => {
        callback("Callback completed");
    }, 1000);
}

function promiseExample() {
    return new Promise((resolve) => {
        setTimeout(() => {
            resolve("Promise completed");
        }, 1000);
    });
}

async function asyncAwaitExample() {
    const result = await promiseExample();
    console.log(result);
}

callbackExample((message) => {
    console.log(message);
});

promiseExample()
    .then((message) => {
        console.log(message);
    });

asyncAwaitExample();

How to Run

node 10.js

Expected Output

Callback completed
Promise completed
Promise completed
