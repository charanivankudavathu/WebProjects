SERVER-06

Demonstrate the File System (fs) module

Create, write, read, and modify a file using Node.js.

Objective

To demonstrate file creation, writing, reading, and appending using the Node.js File System module.

Node.js Code

const fs = require("fs");

const fileName = "sample.txt";

fs.writeFileSync(
    fileName,
    "This file was created using Node.js fs module."
);

console.log("File created successfully.");

const data = fs.readFileSync(
    fileName,
    "utf8"
);

console.log("File Content:");
console.log(data);

fs.appendFileSync(
    fileName,
    "\nThis line was added later."
);

console.log("Content appended successfully.");

How to Run

node 06.js

A file named sample.txt will be created in the current folder.

Expected Output

File created successfully.
File Content:
This file was created using Node.js fs module.
Content appended successfully.
