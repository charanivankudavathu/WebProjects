SERVER-05

Create a Node.js application using built-in modules

Use Node.js built-in modules in a simple application.

Objective

To demonstrate the use of built-in Node.js modules such as OS, Path, and URL.

Node.js Code

const os = require("os");
const path = require("path");
const { URL } = require("url");

console.log("Operating System:", os.platform());
console.log("CPU Architecture:", os.arch());

const filePath = path.join("nodejs", "server", "05.js");

console.log("File Path:", filePath);

const website = new URL(
    "https://example.com/products?id=101"
);

console.log("Hostname:", website.hostname);
console.log("Product ID:", website.searchParams.get("id"));

How to Run

node 05.js

Expected Output

Operating system information
CPU architecture information
File path information
URL hostname and product ID
