EXPRESS-04

Send HTML and JSON responses using Express

Demonstrate sending HTML and JSON data from an Express server.

Objective

To send HTML and JSON responses using Express.js.

Node.js Code

const express = require("express");

const app = express();

app.get("/", (req, res) => {

    res.send(
        "<h1>HTML Response from Express</h1>"
    );

});

app.get("/api/student", (req, res) => {

    res.json({
        name: "Student",
        course: "BTech",
        semester: 3
    });

});

app.listen(3000, () => {

    console.log(
        "Server running at http://localhost:3000"
    );

});

How to Run

node 04.js

HTML response: http://localhost:3000/

JSON response: http://localhost:3000/api/student

Expected JSON Output

{
  "name": "Student",
  "course": "BTech",
  "semester": 3
}
