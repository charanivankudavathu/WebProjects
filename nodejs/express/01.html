EXPRESS-01

Create a basic Express.js application

Create and run a simple web application using Express.js.

Objective

To create a basic Express.js application and send a response to the client.

Installation

npm init -y
npm install express

Node.js Code

const express = require("express");

const app = express();

app.get("/", (req, res) => {
    res.send("Hello from Express.js");
});

app.listen(3000, () => {
    console.log("Express server running at http://localhost:3000");
});

How to Run

node 01.js

Open http://localhost:3000 in your browser.

Expected Output

Hello from Express.js
